# Prefix Page Route (Plop)

- **Generator**: "Prefix Page Route". Creates a prefix route `/{prefix}/{slug}` (e.g. /articles/my-post).
- **Prompts**: `routePrefix` (plural, e.g. articles); `documentType` (singular, e.g. article: the Sanity schema and _type).
- **Creates**: Document schema in `sanity/schemas/documents/{{kebabCase documentType}}.tsx`, with the hidden `language` field (`createLanguageField`); updates `sanity/schemas/index.ts` (import + export); updates `sanity/structure.tsx` (PLOP: Add Structure) with a per-language list (`localeGroupedList`); adds the type to `I18N_DOCUMENT_TYPES` in `sanity/constants.ts` (PLOP: Add Translated Type) so it can be translated; lists its conditionally hidden copy (the SEO title and description) in `CONDITIONAL_PATHS` in `sanity/ai-translation/fields.ts` (PLOP: Add Conditional Paths) so Translate with AI opens them, and gives it its own run step in `RUN_ORDER` (`sanity/ai-translation/plan.ts`, PLOP: Add Run Step), `SITE_GROUP_TITLES` (`site-run.ts`, PLOP: Add Site Group Title, titled by the route prefix in sentence case) and `OWN_SLUG_STEPS` (`dialog-model.ts`, PLOP: Add Own Slug Step), so a whole-site run neither orders nor groups it as a legal page (all four skipped when the project has no Translate with AI); registers the section in `sanity/sections.ts` (PLOP: Add Section Segment, PLOP: Add Section Types) so other languages can name its URL word; page at `src/pages/{{kebabCase routePrefix}}/[slug].astro`; `{{pascalCase documentType}}PageQ` in `src/sanity/queries.ts` (PLOP: Add Route Query). Records the type as the project's own (`scripts/trim-features/own.ts`), then runs `npm run sanity:typegen` and format.
- **Templates**: `templates/page-route/schema.tsx.hbs`, `page.astro.hbs`, `structure.tsx.hbs`, `queries.ts.hbs`. The URI field's `slugify` returns the unprefixed `/{prefix}/{slug}`; `createUriField` moves it into the document's language. Query uses `defineQuery` with `uri.current == $uri && ${ConfiguredLocaleFilter}` (the ghost guard) and projects `${LocaleField}`, `"noIndex": seoMetadata.noIndex == true`, `SeoMetadataFragment` as `${SeoMetadataFragment}` and `${AlternatesFragment}` (single braces in template); `PageQ` already imports all three i18n fragments into `queries.ts`. The SEO fragment calls `frag::image`, so the query opens with `${SeoFunctions}`; the generator adds that import to `queries.ts` when it is missing. The route reads `Astro.locals.path`, takes its locale from `stegaClean(page.language)`, builds `buildAlternateLinks(...)` for the head, passes `lang` and `alternates` to `seo()`, and gives `SiteShell` `showHeader`, `showFooter` and `translations={page.alternates}` (`src/features/i18n/route-wiring.test.ts` checks the template).
- **Do not** remove generated SEO fields or structure entries unless explicitly requested.
